# Getting help with pondok-ai

- **Something is broken?** Run `npx pondok-ai doctor` first, then check [docs/troubleshooting.md](./docs/troubleshooting.md). If that does not help, [open a bug report](https://github.com/rasidi3112/pondok-ai/issues/new/choose) and include the `doctor` output.
- **Questions, ideas, or showing what you built?** Use [GitHub Discussions](https://github.com/rasidi3112/pondok-ai/discussions).
- **GPU setup** (NVIDIA, or Apple Silicon with native Ollama): see [docs/gpu-setup.md](./docs/gpu-setup.md).
- **Security issue?** Please report it privately, see [SECURITY.md](./SECURITY.md).

If pondok-ai is useful to you, a star on GitHub helps other people find it. You can also [sponsor the project](https://github.com/sponsors/rasidi3112).
